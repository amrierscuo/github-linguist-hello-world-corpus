# 0627 — Ruby — `.prawn`

Sorgente Prawn per documento PDF.

Provenienza: esempio originale scritto per il ruolo di questo suffisso.

Artefatto principale: `hello.prawn`.

Controllo previsto, dalla cartella della variante:

```text
ruby -rprawn hello.prawn
```

Risultato atteso: artefatto/risultato originale di saluto nel consumatore indicato.

Stato: creato; sintassi e semantica non verificate.

Questa variante non è ancora stata sottoposta al suo parser/compiler/host originale.

Fonti primarie:

- [https://prawnpdf.org/](https://prawnpdf.org/)
