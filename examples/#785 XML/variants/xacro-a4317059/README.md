# 0785 — XML — `.xacro`

Xacro URDF macro document originale.

Provenienza: esempio originale scritto per il ruolo di questo suffisso.

Artefatto principale: `hello.xacro`.

Controllo previsto, dalla cartella della variante:

```text
xacro hello.xacro -o work/greeting.urdf
```

Risultato atteso: robot.name == Hello, World!.

Stato: creato; sintassi e semantica non verificate.

Questa variante non è ancora stata sottoposta al suo parser/compiler/host originale.

Fonti primarie:

- [https://www.w3.org/TR/xml/](https://www.w3.org/TR/xml/)
- [https://docs.ros.org/en/rolling/p/xacro/](https://docs.ros.org/en/rolling/p/xacro/)
