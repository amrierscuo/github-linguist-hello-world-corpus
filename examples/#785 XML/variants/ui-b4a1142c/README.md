# 0785: XML: `.ui`

Qt Designer UI XML con QLabel originale.

Provenience: original example written for the role of this suffix.

Artefatto principale: `hello.ui`.

Control provided, from the folder of the variant:

```text
uic hello.ui -o work/ui_greeting.h
```

Expected result: UI generated with Hello, World! text.

Status: created; syntax and behavior not verified.
