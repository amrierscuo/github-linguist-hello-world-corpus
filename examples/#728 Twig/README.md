# #728 Twig

Renderizzare un template Twig con default ed escaping.

## Toolchain

Twig PHP engine

## Procedura

Con Twig ufficiale caricare hello.twig e renderizzare name=World; provare anche name=<World>.

## Risultato atteso

Hello, World!

## Stato

Sintassi e semantica in attesa.



Requisiti residui:
- PHP/Twig runtime non predisposto.

## Fonti primarie

- [https://twig.symfony.com/doc/3.x/](https://twig.symfony.com/doc/3.x/)

## Copertura delle estensioni

Le verifiche del campione principale e delle varianti sono registrate separatamente.

| Estensione | File / stato |
| --- | --- |
| `.twig` | [hello.twig](hello.twig) creato, verifiche pendenti |
