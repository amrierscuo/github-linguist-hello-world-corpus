# 0775 — Wolfram Language — `.wls`

Variante testuale dello stesso formato, con suffisso canonico .wls.

Provenienza: copia del file originale `examples/#775 Wolfram Language/hello.wl`.

Artefatto principale: `hello.wls`.

Controllo previsto, dalla cartella della variante:

```text
wolframscript -file hello.wls
```

Risultato atteso: Hello, World! dall’output Print e PASS..

Stato: creato; sintassi e semantica non verificate.

Questa variante non è ancora stata sottoposta al suo parser/compiler/host originale.
