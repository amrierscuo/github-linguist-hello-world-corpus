# 0711 — TeX — `.lbx`

Localization biblatex che ridefinisce una stringa nota senza inventare chiavi.

Provenienza: esempio originale scritto per il ruolo di questo suffisso.

Artefatto principale: `hello.lbx`.

Controllo previsto, dalla cartella della variante:

```text
biblatex: DeclareLanguageMapping{english}{hello}; render bibliography string and
```

Risultato atteso: stringa di localizzazione Hello, World!.

Stato: creato; sintassi e semantica non verificate.

Questa variante non è ancora stata sottoposta al suo parser/compiler/host originale.
