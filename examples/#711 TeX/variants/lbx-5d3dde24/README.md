# 0711: TeX: `.lbx`

Localization biblatex redefines a note string without inventing keys.

Provenience: original example written for the role of this suffix.

Artefatto principale: `hello.lbx`.

Control provided, from the folder of the variant:

```text
biblatex: DeclareLanguageMapping{english}{hello}; render bibliography string and
```

Expected result: Hello, World! localization string.

Status: created; syntax and behavior not verified.

This variant has not yet been subjected to its original parser/compiler/host.
