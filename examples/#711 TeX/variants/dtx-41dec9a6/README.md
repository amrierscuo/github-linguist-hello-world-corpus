# 0711 — TeX — `.dtx`

Sorgente documentato DocStrip con driver e package originali.

Provenienza: esempio originale scritto per il ruolo di questo suffisso.

Artefatto principale: `hello.dtx`.

Controllo previsto, dalla cartella della variante:

```text
pdflatex -output-directory=work hello.dtx
```

Risultato atteso: documentazione originale e macro di saluto.

Stato: creato; sintassi e semantica non verificate.

Questa variante non è ancora stata sottoposta al suo parser/compiler/host originale.

Fonti primarie:

- [https://ctan.org/pkg/docstrip](https://ctan.org/pkg/docstrip)
