# #159 Darcs Patch

The canonical entry and order come from the corpus's `reference/languages.yml`. Sources and fixtures are original; any dumps or bundles come from the stated tools.

## Goal

Apply an original Darcs bundle and get greeting.txt containing Hello, World!.

hello.dpatch is a real bundle patch generated by darcs record/send for an original greeting.txt. Verification applies it to a second local repository and compares bytes. send uses --output and a local path: no emails or requests are sent to external recipients. The empty context exported by the recipient keeps the CONTEXT illustrated header without local paths.

## Toolchain and reproduction

Darcs 2.16.3 release, binario Windows ufficiale

Commands in the example folder with the toolchain available in PATH. Use a temporary copy: databases, objects, audio and other test outputs do not belong to the corpus.

```text
Preparare due repository locali origin e receiver con darcs init.
Da receiver: darcs log --context > ../origin/receiver.context
Da origin: darcs add greeting.txt; darcs record --all --name "Add original corpus greeting" --author "Corpus Example <corpus@example.invalid>"
darcs send --all --no-edit-description --no-set-default --context receiver.context --output hello.dpatch ../receiver
```

```text
Nel repository locale destinatario vuoto: darcs apply --all hello.dpatch
```

## Expected result and status

Applicazione exit 0 e greeting.txt esattamente Hello, World! seguito da newline.

Artifact created: yes. syntax verified: yes. behavior verified: yes.
