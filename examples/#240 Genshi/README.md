## Goal

Render a Genshi .kid template with World audience and get a Hello, World! paragraph.

MarkupTemplate interprets py:content and audience=World context. The resulting string replaces the template placeholder. Control compares the markup actually generated by the original maker.

Commands in the example folder with the tools available in PATH. Use a temporary copy for build and output; test dependencies are isolated in work.
