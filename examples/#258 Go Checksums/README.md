# #258 Go Checksums

Use an authentic go.sum to solve x/text addiction and generate Hello, World! with conversion homes.

## Toolchain

go version go1.27.1 windows/amd64

## Commands and procedure

go mod tidy; go mod verify; go mod download -json golang.org/x/text@v0.31.0; go run .

## Expected result

go.sum generated by the tools; checksum verified; Hello, World! print program more newline.

## Status

syntax and behavior verified.

The h1 values are produced by Go for the original module and its go.mod; they are not written manually. go mod verify the contents of the cache module. main.go really uses cases.Title, and go.mod provides the context of the checksum format.

Actual verification of 2026-10-08T12:16:15.315614+00:00 on Windows x64: [log](verification/result.json).
