# #836 xBase

Compilare ed eseguire un programma xBase.

## Toolchain

Harbour xBase compiler/runtime

## Procedura

hbmk2 hello.prg -obuild/hello; build/hello

## Risultato atteso

Hello, World!

## Stato

Sintassi e semantica in attesa.



Requisiti residui:
- Harbour/xBase compiler/runtime non predisposti.
