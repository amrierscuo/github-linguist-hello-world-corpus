# #067 Bison

Canonical entry from the corpus's `reference/languages.yml`. The reference and its order remain unchanged. The source was written for this example.

## Goal

Generate a Bison parser that accepts EOF and Hello, World! print through the action of the empty rule.

The lexer returns EOF. The parser C is generated by the real and compiled Bison tool; the generated outputs remain out of the corpus.

## Toolchain and reproduction

GNU Bison 3.8.2 tramite WinFlexBison 2.5.25; GNU C 13.3.0 su Ubuntu WSL

Command from the example folder, with the toolchain indicated available in the PATH. Run the build in a temporary copy to keep the generated files out of the corpus.

```text
win_bison -Wall -Werror --output=hello.c hello.bison
gcc -std=c11 -Wall -Wextra hello.c -o hello
```

```text
./hello
```

## Expected result and status

EOF accettato, stdout esatto Hello, World! seguito da newline; exit 0.

Artifact created: yes. syntax verified: yes. behavior verified: yes.
