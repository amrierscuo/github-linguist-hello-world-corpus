# 0789 — XQuery — `.xql`

Variante testuale dello stesso formato, con suffisso canonico .xql.

Provenienza: copia del file originale `examples/#789 XQuery/hello.xq`.

Artefatto principale: `hello.xql`.

Controllo previsto, dalla cartella della variante:

```text
basex hello.xql
```

Risultato atteso: Hello, World! serializzato come testo..

Stato: creato; sintassi e semantica non verificate.

Questa variante non è ancora stata sottoposta al suo parser/compiler/host originale.
