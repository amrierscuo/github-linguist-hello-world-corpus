# #012 ANTLR

`Hello.g4` defines a ANTLR grammar 4 which recognizes the literal greeting
`Hello, World!`, possible blank space and the end of input. ANTLR is a language
by grammars: the semantic goal is to recognize the message, not to attribute
to grammar a printing instruction. `hello.txt` is the input and `CheckHello.java`
is a verification that uses the lexer and the parser really generated by ANTLR.

## Toolchain and commands

They serve JDK 11+ and JAR complete ANTLR 4.13.2 from the official page.
example folder, set `$AntlrJar` to the JAR path and launch:

```powershell
New-Item -ItemType Directory -Force -Path .build | Out-Null
java -jar $AntlrJar -Werror -o .build Hello.g4
javac -encoding UTF-8 -cp $AntlrJar -d .build .build/HelloLexer.java .build/HelloParser.java .build/HelloListener.java .build/HelloBaseListener.java CheckHello.java
java -cp ".build;$AntlrJar" CheckHello hello.txt
```

On Linux/macOS the classpath separator is `:` instead of `;`.

## Verification performed

syntax and behavior verified con ANTLR 4.13.2 e OpenJDK 21 su Windows.
The generation with `-Werror` and Java compilation have succeeded.:

```text
(message Hello, World! <EOF>)
Negative controls rejected: wrong greeting, trailing text, empty input
```

Verifier controls errors both of the lexer and of the parser, the content
the generated files and JAR remain out of the corpus;
see `verification.log` for commands, origin and toolchain footprint.
