# #577 Quake

Eseguire un m3makefile nel linguaggio Quake del build system Modula-3.

## Toolchain

CM3 Quake interpreter

## Procedura

cm3 -build nella cartella del progetto di prova con questo m3makefile; registrare output e versione.

## Risultato atteso

Hello, World!

## Stato

Sintassi e semantica in attesa.

Il nome canonico m3makefile identifica il linguaggio di scripting del build system Modula-3.

Requisiti residui:
- Build interpreter CM3/Quake non disponibile.
