# 0635: SQF: `.hqf`

Header SQF of preprocessor, included by a companion program.

Provenience: original example written for the role of this suffix.

Artefatto principale: `hello.hqf`.

Control provided, from the folder of the variant:

```text
Arma SQF preprocessFileLineNumbers main.sqf; execute compiled result
```

Expected result: diag_log reports Hello, World!.

Status: created; syntax and behavior not verified.
