# 0791 — XSLT — `.xslt`

Variante testuale dello stesso formato, con suffisso canonico .xslt.

Provenienza: copia del file originale `examples/#791 XSLT/hello.xsl`.

Artefatto principale: `hello.xslt`.

Controllo previsto, dalla cartella della variante:

```text
xsltproc hello.xslt input.xml
```

Risultato atteso: Hello, World! come risultato testuale della trasformazione..

Stato: creato; sintassi e semantica non verificate.

Questa variante non è ancora stata sottoposta al suo parser/compiler/host originale.

Fonti primarie:

- [https://www.w3.org/TR/1999/REC-xslt-19991116](https://www.w3.org/TR/1999/REC-xslt-19991116)
