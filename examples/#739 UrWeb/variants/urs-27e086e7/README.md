# 0739 — UrWeb — `.urs`

Signature UrWeb corrispondente al modulo di pagina originale.

Provenienza: esempio originale scritto per il ruolo di questo suffisso.

Artefatto principale: `hello.urs`.

Controllo previsto, dalla cartella della variante:

```text
urweb hello
```

Risultato atteso: signature accettata e pagina Hello, World!.

Stato: creato; sintassi e semantica non verificate.

Questa variante non è ancora stata sottoposta al suo parser/compiler/host originale.

Fonti primarie:

- [https://www.impredicative.com/ur/tutorial/](https://www.impredicative.com/ur/tutorial/)
