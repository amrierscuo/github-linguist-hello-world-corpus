# #739 UrWeb

Compilare una pagina UrWeb e leggerla via HTTP locale.

## Toolchain

UrWeb compiler/runtime

## Procedura

urweb hello; ./hello.exe; leggere la pagina main dalla porta locale indicata.

## Risultato atteso

Hello, World!

## Stato

Sintassi e semantica in attesa.



Requisiti residui:
- UrWeb compiler/runtime e dipendenze native non predisposti.

## Fonti primarie

- [https://www.impredicative.com/ur/tutorial/](https://www.impredicative.com/ur/tutorial/)
