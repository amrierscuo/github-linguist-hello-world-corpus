# 0771 — Wikitext — `.wikitext`

Variante testuale dello stesso formato, con suffisso canonico .wikitext.

Provenienza: copia del file originale `examples/#771 Wikitext/hello.mediawiki`.

Artefatto principale: `hello.wikitext`.

Controllo previsto, dalla cartella della variante:

```text
MediaWiki parser: render hello.wikitext
```

Risultato atteso: Titolo Greeting, testo Hello, World! e PASS..

Stato: creato; sintassi e semantica non verificate.

Questa variante non è ancora stata sottoposta al suo parser/compiler/host originale.
